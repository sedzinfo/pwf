## Ground rules
- Don't run tests/reference/make_reference.R casually: it rewrites the committed references. It is
  meant to run on Windows R 4.6.2 and writes LF through a binary connection. For comparisons, write
  your own R scripts outside the repo.
- The work machine (Linux) has R 4.6.2, rwf 0.1.0 and lavaan 0.7.3, and its R uses OpenBLAS. Elsewhere,
  install R and rwf (github.com/sedzinfo/rwf) before comparing with rwf. The pytest suite itself needs no R.
- The repo's venv/ is stale (pwf isn't installed in it). Make a fresh venv outside the repo with
  `pip install -e ".[full]" pytest`. A non-editable `pip install .` leaves build/ and
  src/pwf.egg-info behind (both ignored).
- Don't commit or push: the owner does that.
